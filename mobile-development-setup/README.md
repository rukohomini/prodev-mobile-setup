# Mobile Development Environment Setup

## Objective

This task focuses on setting up and testing my mobile development environment using **Expo Go** for React Native development. Since mobile development can be more demanding than web development, Expo Go helps simplify testing by allowing me to run apps directly on my physical device.

---

## My Development Setup

Before starting this task, I already had the following installed on my system:

* **Node.js (LTS version)**
* **Visual Studio Code (VS Code)**
* **Operating System:** Windows
* **Reliable internet connection**

These tools ensured I was ready to proceed with the Expo setup.

---

## Why I Chose Expo Go

Setting up mobile emulators can be stressful and resource-heavy, especially with frequent device and OS updates. Expo Go stood out as a simple and efficient alternative because it allows me to test React Native applications instantly on my physical device.

What I like about Expo Go:

* No need to install or manage emulators
* Live preview of apps in real time
* Works smoothly on both Android and iOS
* Beginner-friendly setup

---

## Expo Go Installation Process

### Step 1: Accessing Expo Go

* I visited the official Expo Go page at [https://expo.dev/go](https://expo.dev/go)
* I selected the latest available SDK version

### Step 2: Installing the App

* I installed **Expo Go** from the **Google Play Store** on my Android device
  *(For iOS, the app is available on the Apple App Store)*

### Step 3: Account Setup

* I opened the Expo Go app on my phone
* I created an Expo account and logged in successfully

---

## Testing and Verification

* The Expo Go app launched without any issues
* I confirmed that the app is ready to scan QR codes
* This means my device is now fully prepared to run Expo-based React Native projects

---

## Challenges I Faced

* The app download took longer than expected due to a slow internet connection
* Email verification for my Expo account was slightly delayed

Despite these minor issues, I was able to complete the setup successfully.

---

## What I Learned

This setup helped me understand how Expo Go simplifies mobile development and reduces dependency on heavy system resources. I now feel more confident moving into React Native mobile app development.

---

## Conclusion

My mobile development environment is now properly set up and tested. With Expo Go installed and working, I am ready to proceed with upcoming mobile development projects using React Native.
